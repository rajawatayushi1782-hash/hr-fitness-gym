# Copyright-Free Gym Assets Directory

This directory contains the dedicated backup of all original reference assets as well as clean copies of all new copyright-free replacement gym assets.

## Directory Structure:

- **`original-assets-backup/`**:
  - Full backup of the 142 original reference assets downloaded from `https://go180.nl/` (`images/`, `videos/`, `logos/`, `icons/`, `fonts/`, `3d/`).
  - Preserved separately to ensure original source files are never lost or corrupted.

- **`images/`**:
  - 100 replacement gym and fitness images sourced from **Unsplash** and **Pexels**.
  - All images are encoded in high-resolution WebP format with dimensions exactly matched to the original layout requirements (e.g. 1920x648, 1500x1000, 790x860, 1920x1080).
  - Licensed under the **Unsplash License** and **Pexels License** for free commercial and personal use with zero attribution required.

- **`videos/`**:
  - Contains `header.mp4` (8.40 MB, 1920x1080 Full HD, 30 FPS).
  - High-energy gym workout video featuring battle ropes and functional fitness training.
  - Sourced from **Pexels Video** under the **Pexels License** for free commercial use.

For the full audit and source URLs for all 101 replaced media assets, see [`COPYRIGHT_FREE_REPLACEMENT_REPORT.md`](../COPYRIGHT_FREE_REPLACEMENT_REPORT.md).
